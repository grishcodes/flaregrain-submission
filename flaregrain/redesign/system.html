(System design)How Flaregrain is built

Five layers, from NASA’s sources to the page. Every number below comes from the team’s build and evaluation files. The full system runs in the live demo; this site carries its 13 hand-checked records.

  1. 01

    NASA sources and intake

    Fetches NASA’s Physical Sciences Informatics (PSI) combustion repository and the investigators’ report PDFs, and keeps a checksum for every file it reads.

    PSI combustion investigations
    2,009

  2. 02

    Normalized data

    Every printed value becomes one normalized value with its unit and its source cell. Each value carries its provenance: checked NASA record PSI table row Flaregrain model or reading context, plus flagged and disputed states. Where two NASA sources disagree, both values stay visible.

    24,573
    normalized values
    13
    hand-checked NASA records, 11 of them comparable runs
    575
    table values flagged, each with the reading the team takes

    An overnight statistical sweep proposed 861 candidate issues for a second reading. A separate cross-check of table rows against the report text found both known Saffire II disputes on its own. Questioned values get a second reading before they are published.

    Codebuild_dashboard_catalog.py build_issues_summary.py

  3. 03

    Retrieval and ranking

    Cuts the report PDFs into passages and ranks investigations for a plain-language question by rules: names, materials, conditions and outcomes. It is measured on a draft set of 30 questions, each asked four ways (plain, technical, short and misspelled).

    1,595
    report passages from the 9 PDFs
    0.850
    recall@5, rules only
    0.833
    hit@1, rules only

    The scores cover the 108 wordings that have an expected answer; the other 12 should get none. With the live model added, an earlier overnight run measured hit@1 0.806 and recall@5 0.839. The model returned a reading for only 22 of the 120 wordings in that run.

    Codebuild_report_passages.py 07a-report-search.js 02-investigations-and-coverage.js Evaluation checks.mjs

  4. 04

    Sentence checker

    Every sentence the model writes is kept only if it matches the record fields it cites. Numbers, units, record names and words are checked against those fields. Sentences that state a disputed value as fact, add a cause, or cite nothing are removed.

    139
    saved explanations: 492 sentences kept, 270 removed
    343,758
    synthetic test sentences, over 55 record pairs
    0
    misses for wrong numbers, wrong records, cause words, missing citations and disputed values
    920 → 240
    wrong-unit misses per sentence framing, after two fixes

    The saved explanations were written by qwen3:4b (Ollama 0.40.16) and kept only where they passed. The stress test is a team run on the Mac Mini; its harness is not yet in this repository. Known gap: invented details that reuse words from the cited fields often pass. In the same test, 19,520 of 23,040 per framing did. That is why model text is always labelled as Flaregrain’s reading and never styled as NASA evidence.

  5. 05

    Interface

    Nora’s Ask, Compare, Evidence and Browse. Every answer links to the NASA page it came from. Model text carries the label “Flaregrain reading · not NASA evidence”. The model, qwen3:4b, runs locally on the team’s Mac Mini and is shown live in the demo. This public site shows only saved, checked text.
